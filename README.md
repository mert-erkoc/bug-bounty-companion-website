# Bug Bounty Companion Marketing Website

This is the production-ready marketing website for **Bug Bounty Companion**, a browser-native toolkit for bug bounty hunters and penetration testers.

Built with **React**, **Vite**, and **TailwindCSS**.

## Features

- **Hero Section**: Premium value proposition with clean calls to action.
- **Interactive Mockups**: High-resolution, vector-sharp UI mockups built with React components.
- **Feature Grid**: Comprehensive list of implemented extension capabilities.
- **Why BB Companion**: Highlights of privacy, speed, and browser-native workflow.
- **Coming Soon**: Beautiful showcase of upcoming Pro features.
- **SEO Optimized**: Meta tags, Open Graph, Twitter cards, robots.txt, and sitemap.xml.
- **Responsive**: Fully optimized for mobile, tablet, and desktop.
- **Animations**: Tasteful, lightweight scroll animations using Framer Motion.

## Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: TailwindCSS
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Type Safety**: TypeScript

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Deployment

This project is optimized for **Vercel**. Simply connect your repository and it will deploy with zero additional configuration.
